VariableПеременнаяАйнымалы

FunctionФункцияФункция

A named set of commands: function hit(){}. Call it: hit().Набор команд с именем: function hit(){}. Вызов: hit().Аты бар командалар жиыны: function hit(){}. Шақыру: hit().

ArrayМассивМассив

DOMDOMDOM
